# SmartGrid — система розподілу електроенергії

Практична робота №1 

## Як працює застосунок

1. **Вхід / реєстрація оператора** (тестовий вхід: `operator@grid.ua` / `123456`).
2. **Головний екран** з нижнім меню:
   - **Моніторинг** — навантаження, частота, завантаження підстанції, кнопка оновлення;
   - **Розрахунок** — потужність, втрати й ККД лінії за U, I, cosφ, R;
   - **Режими** — денний / нічний / піковий / аварія; режим змінює навантаження, яке видно й у моніторингу.

## Структура

```
app/src/main/java/ua/kpi/smartgrid/
├── MainActivity.kt          вхід → головний екран
├── screens/
│   ├── LoginScreen.kt       вхід і реєстрація (заняття 4)
│   ├── MainScreen.kt        нижнє меню, спільний стан навантаження
│   ├── MonitoringScreen.kt  моніторинг (заняття 1)
│   ├── CalculatorScreen.kt  розрахунок лінії (заняття 2)
│   └── ModesScreen.kt       режими мережі (заняття 3)
├── data/
│   ├── Calculator.kt        формули
│   ├── AuthValidator.kt     перевірка форм
│   └── UserStorage.kt       список користувачів
└── ui/theme/                кольори, тема, шрифти
```
